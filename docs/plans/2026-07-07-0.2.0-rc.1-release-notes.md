## Huml.Net 0.2.0-rc.1

First release candidate for 0.2.0 stable, closing out the beta feedback window
(beta.1 shipped 2026-06-13; beta.2 on 2026-07-01). Bug-fix-only per the 0.2.x line policy
([docs/versioning.md](../versioning.md)).

### Fixed

- **Overridden and `new`-shadowed properties no longer serialise twice.** The reflection
  binding path emitted one `key: value` line per *declaration* when walking an inheritance
  chain, so any hierarchy using `virtual`/`override` (or `new`-shadowing) produced invalid
  HUML that Huml.Net's own parser rejected on round-trip with "Duplicate key". Properties are
  now de-duplicated with the derived-most declaration winning, at the base-most declaration's
  position. The source generator received the matching fix for `new`-shadowed properties,
  which previously read the *base* declaration's value; the reflection and source-generated
  paths now produce identical output, pinned by a parity test. (#TASK-019)
- **Stale XML doc on `HumlOptions.TypeInfoResolver`** — the remarks claimed the resolver was
  not yet consumed; it has been consumed by both the serialiser and deserialiser since
  0.2.0-alpha.4. The doc now describes the actual behaviour.

### Added

- **Build-time public API freeze enforcement** — `Microsoft.CodeAnalysis.PublicApiAnalyzers`
  now guards the public surface against per-TFM baselines in `src/Huml.Net/PublicAPI/`; any
  undeclared public-surface change fails the build (RS0016/RS0017). Analyzer-only
  (`PrivateAssets="All"`): the shipped package keeps **zero runtime dependencies**. No change
  to the package itself. (#TASK-003)

### Dependency housekeeping

- Meziantou.Analyzer 3.0.102 → 3.0.117, Microsoft.NET.Test.Sdk 18.6.0 → 18.7.0 (build/test
  only; dependabot #31), and pinned GitHub Actions bumps (dependabot #28). None affect the
  shipped package.
